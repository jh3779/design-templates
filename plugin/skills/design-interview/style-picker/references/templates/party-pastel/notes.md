# party-pastel

## 한 줄 요약
따뜻한 오프화이트 바탕 위 라벤더 포인트, 파스텔(코랄·민트·바이올렛) 장식 카드, 기울어진 손글씨 메모, 펠트 테이블 미리보기로 구성한 캐주얼 파티 게임 로비 템플릿입니다.

## 출처
- 프로젝트: yangsaechan-game (양세찬 게임, "Party Aurora" 디자인 시스템)
- 토큰: docs/design-system/tokens.css:4-52(라이트), :53-81(다크 `[data-ds-theme="dark"]`)
- 베이스·포커스·reduced-motion: docs/design-system/base.css:11-31, 65-68, 143-151
- 버튼·배지·탭·아바타: docs/design-system/components.css:2-49, 70-94, 139-159, 298-328
- 히어로·이름 카드·손글씨 주석: docs/design-system/screens.css:26-171, 입장 카드 :172-240, 진행 방법 :241-284
- 주사위 로고·게임 카드 아트·타일: frontend/home.css:11, 37-51, 120-236
- 펠트 트레이: frontend/yahtzee-table.css:1-83, 198-201 / 카드 뒷면·슈·플립: frontend/card-motion.css:31-76, frontend/card-motion.js:120-195

## 연결 스타일
미니멀리즘(친근한 변주)에 가장 가깝습니다. 넓은 여백·단일 포인트 색·얇은 보더 위에 파스텔 장식과 손글씨로 온기를 더한 형태이며, 방 목록+테이블 카드 배치는 벤토 그리드의 요소가 약간 섞여 있습니다.

## 이럴 때 제안
- 친구·소모임용 파티 게임, 퀴즈, 보드게임 로비와 방 목록
- "친근하게, 하지만 유치하지 않게" 요청을 받은 커뮤니티·이벤트 참여 화면
- 로그인 없이 코드로 입장하는 가벼운 협업·투표·초대 흐름

## 시그니처 패턴
1. 서로 반대로 기운 파스텔 이름 카드 3장 + 흐린 코랄/바이올렛 블롭 + 손글씨 주석
2. 회전한 손글씨 스티커 메모(입장 카드 모서리, 섹션 헤더 옆)
3. 주사위 점 로고, -6° 기울어진 게임 글리프 등 "살짝 비뚤어진" 작은 오브젝트
4. 펠트+나무 테두리 트레이에 아이보리 카드·타일을 CSS로 그리고, 슈에서 날아와 뒤집히는 모션
5. 2px 보더 방 카드, 선택 시 primary 보더 + primary-container 링

## 적용 시 바꿀 것
- 브랜드명(모여놀자), 히어로 카피, 게임 이름과 방 데이터(모두 예시 값)
- 펠트 테이블은 장르에 맞게 교체(퀴즈라면 칠판, 보드게임이라면 보드판)
- 손글씨 메모는 화면당 2–3개 이하로 유지해야 분위기가 삽니다
- 테마 저장 키(localStorage "party-pastel-theme")와 토스트 문구

## 알려진 한계
- 원본 다크 셀렉터는 `[data-ds-theme]`이며 템플릿은 계약에 맞춰 `[data-theme]` + prefers-color-scheme로 바꿨습니다. 그래서 다크 토큰 블록이 두 번 반복됩니다.
- 카드 모션은 원본의 오버레이 복제 방식 대신 카드 자체에 WAAPI를 거는 단순화 버전입니다.
- 375px에서 히어로 카드 묶음을 82%로 축소하기 때문에 좌우 끝이 살짝 잘리고 손글씨 주석이 일부 가려집니다.
- 헤드리스 Chrome은 창 너비가 최소 500px이라 모바일 미리보기는 390px iframe으로 렌더링했습니다.
- 게임 아트 외 아이콘은 인라인 SVG 4종뿐입니다.
