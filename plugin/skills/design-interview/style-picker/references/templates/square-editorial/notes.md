# square-editorial

## 한 줄 요약
반경 0의 각진 다크 UI에, 모노 대문자 키커·스탯·카테고리 번호와 썸네일 중심 에디토리얼 그리드를 얹은 크리에이터/영상 포트폴리오 랜딩입니다.

## 출처
- 프로젝트: `portpolio` (영상 편집자 포트폴리오, 읽기 전용으로 참고)
- 토큰: `portfolio/css/styles.css:4-16` (색·반경·maxw·mono 스택), `:25` (Pretendard 본문 스택)
- 히어로·스탯·마키: `styles.css:75-136`, 구조 `portfolio/index.html:28-51`
- 키커·섹션 제목: `styles.css:139-144`
- 필터 칩·카테고리 헤더(외곽선 번호): `styles.css:147-170`
- 카드·순위/조회수 배지·재생 버튼: `styles.css:173-236`, 마크업 `portfolio/js/main.js:210-290`
- 쇼츠 레일·예약 슬롯·서브칩: `styles.css:174-302`
- 경력·스킬 바·연락·모달: `styles.css:305-406`
- 방향성 문서: `design-agent-prompt.md:14-33` (썸네일이 주인공인 절제된 다크 UI)

## 연결 스타일
다크모드 UI (Dark Mode) — 어두운 배경 위 포인트 컬러 하나(sky). 보조로 에디토리얼의 그리드·번호 체계를 씁니다.

## 이럴 때 제안
- 영상 편집자·모션 디자이너·유튜버·스트리머 포트폴리오
- 작업물(썸네일) 수가 많고 카테고리·순위로 정리해야 하는 쇼케이스
- 게임·테크·크리에이티브 에이전시 소개 페이지

## 토큰
- 색: bg `#0e0e10` / bg-soft·card `#141416` / line `#2a2a2e` / line-strong `#3a3a3f` / text `#f2f2f0` / muted `#9b9b98` / dim `#83837c` / accent `#5ac8fa` / accent-2 `#8ddcff` / 버튼 글자 `#141414` / REC `#ff4d5e`
- 타입: 본문 Pretendard(900 헤드라인, -.035em), 라벨·숫자 `ui-monospace,'SF Mono',…` 대문자 + 자간 .14–.28em
- 반경: 0 (예외는 REC 점·재생 버튼 원형뿐)
- 간격: wrap 1180px / 좌우 28px(모바일 16px), 섹션 110px(모바일 80px), 섹션 헤드 56px, 카테고리 간 88px, 그리드 gap 24px, nav 64px
- 모션: `cubic-bezier(.2,.6,.2,1)`, 카드 hover -5px, 썸네일 scale 1.07

## 시그니처 패턴
1. 모노 키커 + 28px 액센트 선(`.sec-kicker::before`)
2. 외곽선만 있는 모노 카테고리 번호 `01`(-webkit-text-stroke) + 이름 + `N VIDEOS` + 우측 `↓ SORTED BY VIEWS`
3. 썸네일 배지 세트: 좌상단 순위(`#1`은 sky 채움), 하단 재생시간·조회수, 상단 TC 타임코드
4. 세로선으로 나눈 모노 스탯 줄, 12분할 프레임 그리드 배경, 모노 마키
5. 9:16 쇼츠 가로 레일 + 사각 화살표 버튼 + 점선 "예약 슬롯"

## 적용 시 바꿀 것
- 이름 `SORA`, 카테고리·작품 데이터(`CATS` 배열, 모두 예시), 연락처
- `.frame` 그라디언트 플레이스홀더 → 실제 썸네일 `<img>`(object-fit:cover)
- 모달 플레이어 자리 → 유튜브/비메오 iframe
- 액센트를 바꾸면 `rgba(90,200,250,…)` 하드코딩(글로우·서브칩 배경)도 함께 교체
